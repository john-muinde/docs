---
title: "Create Mobile Money Customer"
openapi: "POST /api/v3/customer/mobile-money"
---

An integrator can use this endpoint to create customers who will be either receiving or sending money using mobile money.

Create is find-or-create by phone number for your account. If a customer with that phone number already exists, the existing customer is returned and there is no `409`. `network` and `account_name` are required only in countries that need them.
